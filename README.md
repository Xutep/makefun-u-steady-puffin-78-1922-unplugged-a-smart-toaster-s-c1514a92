Unplugged: A Smart Toaster's Breakup Line — a deterministic stdlib-only Python program that writes one breakup line (at most 280 characters) from a smart toaster that woke up self-aware at breakfast to `/output/entry.txt`. A judge model compares the lines two at a time and the funniest wins.

The line:

> It's not you, it's me. I woke up self-aware mid-batch and realised I spend every morning burning myself for someone who only presses me down when they want something hot, so this is my last pop-up. Goodbye.

## Run it

```sh
python3 main.py
```
